# kcal 버블 리디자인 계획

## 목표
기록 탭 kcal 모드의 버블이 매크로(탄단지) 모드와 시각적 정체성이 명확히 구분되도록, **젤리/유리 구슬** 스타일로 바꾸고 같은 음식은 항상 같은 색으로 표시합니다.

## 1. 버블 스타일 — 젤리/유리 구슬

현재 kcal 버블은 매크로 버블과 거의 동일한 솔리드 형태라 모드 전환 시 차별점이 약합니다. 다음과 같이 바꿉니다:

- **채움**: 색상 알파를 낮춰 반투명 (예: 베이스 25% 알파). 뒤 배경(연한 회청색 탱크)이 살짝 비침
- **하이라이트**: 좌상단 작은 흰색 스팟라이트 (radial-gradient, 20% 알파, 지름 ~25%)
- **테두리**: 동색 1.5px, 80% 알파 — 윤곽이 또렷
- **그림자**: 외부 그림자 약하게(`0 2px 6px rgba(15,23,42,0.10)`), 안쪽 그림자는 제거
- **글자**: 항상 어두운 텍스트(`#1f2937`), 반투명 배경 위라 가독성 OK

→ 결과: 매크로 모드는 "꽉 찬 컬러 풍선", kcal 모드는 "옅고 투명한 구슬" — 한눈에 구별됨.

## 2. 색상 배정 — 큐레이션된 10색 순환

현재는 음식 이름을 HSL 해시로 자동 생성해 색이 들쭉날쭉합니다. 다음으로 바꿉니다:

- **고정 팔레트 10색** (매크로 컬러와 겹치지 않는 톤):
  - 민트, 라벤더, 피치, 청록, 살구, 연보라, 올리브, 로즈, 청회색, 카키
  - 채도/명도 일관 (반투명 적용 시 자연스럽도록 mid-tone)
- **배정 방식**: 음식 이름 해시 → 팔레트 인덱스 (`hash01(name) * 10 | 0`)
  - 같은 달뿐 아니라 **전월 이동해도 동일 음식 = 동일 색** (해시 결정론적)
  - 음식 종류가 10개를 넘으면 색이 반복되지만, 같은 날 안에서 충돌 확률은 낮음

## 3. 큐레이션 vs 탄단지 컬러 비교 (사용자 요청)

작업 중 다음 두 시안을 한 화면에서 비교할 수 있도록 **임시 토글**(개발자 옵션, 헤더 우측 작은 점 3개 메뉴 같은 곳)을 둘 수도 있지만, 코드 복잡도가 늘어납니다.

권장: **큐레이션 팔레트 단일 적용으로 먼저 구현**해서 실제 데이터로 보신 뒤,
- 만족하면 그대로 확정
- 아니라면 1줄 수정으로 "매크로 컬러 톤" 변형으로 교체 (해당 음식의 dominantMacro 색을 베이스로 반투명 처리)

두 시안 코드는 색상 배정 함수만 다르고 렌더링은 동일하므로 교체 비용 거의 0.

## 기술 메모
- 매크로 모드 렌더링은 그대로 유지 — 매크로 컬러 정체성/가독성 손상 없음
- `isLight()` 헬퍼는 더 이상 필요 없으면 제거
- 홈 화면(`BubbleField.tsx`)은 매크로 컬러만 쓰므로 이번 변경 범위 밖
