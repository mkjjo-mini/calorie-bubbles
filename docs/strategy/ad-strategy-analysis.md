## 1. 결정 요약

**현재 광고 구성**: 배너 광고만 (Free 사용자 홈 하단)
**보류된 작업**: 전면 광고 (Interstitial) — 식사 기록 N회마다 노출
**보류 이유**: 칼로리 트래커 retention 민감 + 광고 수익 < 결제 수익. Pro 가치 강화가 LTV에 더 큰 영향.

---

## 2. 사업 모델 컨텍스트

### 현재 BM (Step 17 entitlements)
| Tier | 월 | 핵심 차별점 |
|---|---|---|
| Free | ₩0 | 광고 노출, AI lifetime 3회 |
| Basic | ₩1,900 | **광고 제거만** |
| Pro | ₩4,900 | AI 무제한, 과거 편집, 알림, 마법사 |

### 약점
- **Basic 가치 약함** — "광고 제거"가 유일. 배너만 있을 땐 가치 더욱 작음.
- 사용자 결제 흐름이 Free → Pro 직진 구조에 더 가까움.

---

## 3. 칼로리 트래커 특성

| 특성 | 광고 적합성 |
|---|---|
| 매일 5~10회 사용 (식사마다) | 광고 노출 빈도 자연 ↑ → 부담 ↑ |
| 빠른 기록이 핵심 가치 | 전면 광고가 기록 흐름 끊음 → 가치 훼손 |
| Retention 민감 (식사 트래커 90일 retention < 20%) | 광고 부담 = 이탈 ↑ |
| 식사 시간마다 사용 | 광고가 식욕 분위기 깸 (전면일 때 더 큼) |

→ **광고 부담에 가장 민감한 카테고리 중 하나**.

---

## 4. 수치 비교 (1만 MAU 보수적)

### 광고 수익 (월)
| 광고 모델 | 월 수익 |
|---|---|
| 배너만 (현재) | $70~100 (~₩90~130k) |
| 배너 + 전면 (5회마다) | $170~220 (~₩220~290k) |
| 배너 + 전면 (3회마다) | $230~280 (~₩300~365k) |

### 결제 수익 (월)
| 사용자 비율 | 월 수익 |
|---|---|
| Pro 1% (100명) × ₩4,900 | ₩490,000 (~$377) |
| Basic 2% (200명) × ₩1,900 | ₩380,000 (~$292) |

### 핵심 인사이트
- 전면 광고 추가로 얻는 **수익 증가분 = 월 $100~150** (~₩130~200k)
- **Pro 결제율 1%p 향상 = 월 +₩490,000** — 전면 광고 전체보다 큼
- → **광고 추가보다 Pro 가치 강화가 BM 성장의 진짜 액션**

## 5. 옵션 비교

### A. 전면 광고 추가 (보류된 옵션)
| 장점 | 단점 |
|---|---|
| 광고 수익 +$100~150/월 | Retention 손해 (이탈 ↑) |
| Basic 가치 ↑ (배너+전면 둘 다 제거) | 평점 ↓ (광고 많은 앱 리뷰 부정적) |
| 사용자 압박으로 Basic 전환 유도 | 첫 인상 ↓ (전면은 가입 초기 큰 부담) |

### B. 배너만 유지 ⭐ (결정)
| 장점 | 단점 |
|---|---|
| 사용자 부담 최소 | 광고 수익 작음 |
| Retention 보호 → LTV ↑ | Basic 가치 미미 |
| 평점 안전 | |
| 출시 후 데이터 보고 재검토 가능 | |

### C. Pro 가치 강화 + Basic 제거 (장기 옵션)
| 장점 | 단점 |
|---|---|
| Pro 결제로 직접 수익 — 광고 의존 X | Pro 가치 강화 작업 필요 (차트/추천/통계 등) |
| LTV 극대화 | Basic 사용자 잃음 (사실 가치 약해서 손해 적음) |
| 단순 BM (Free vs Pro 2-tier) | BM 재설계 작업 |

## 6. 보류 / 보류 해제 조건

### 출시 후 모니터링 지표
- DAU/MAU 비율
- 1주 / 1개월 / 3개월 retention 곡선
- Free → Basic 전환률
- Free → Pro 전환률
- 광고 노출당 평균 세션 길이 변화

### 전면 광고 도입 재검토 트리거
- ✅ Free 사용자 retention 30일 > 30% (사용자가 충성)
- ✅ Basic 결제율 < 2% (Basic이 약해서 추가 차별점 필요)
- ✅ Pro 결제율 > 3% (수익 모델 검증) → 광고 부담 추가해도 위험 낮음
- ✅ App Store 평점 > 4.0 (광고 추가해도 평점 여유)

→ 이 4가지 모두 충족 시 전면 광고 도입 재검토.

### 전면 광고 영구 보류 트리거
- App Store 평점 < 3.5 → 광고는 평점 더 깎음, 위험 크므로 영구 보류
- Pro 결제율이 BM 핵심으로 자리 잡음 → 광고 의존 X

- **첫 사용 보호 24시간**: 사용자 결정 "혜택 인지 못하면 의미 없음" → 보호 X
- **Basic 3일 무료 체험**: 검토 → "사용자가 혜택 모르고 끝나는 게 더 안 좋음" → 폐기
