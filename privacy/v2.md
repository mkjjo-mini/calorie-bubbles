# 탄단지버블 개인정보처리방침

- **버전:** v2 · **시행일:** 2026-06-01
- **제·개정일:** 2026-05-23
- **관련 문서:** [이용약관 v2](../terms/v2.html)

아임나코805(이하 "회사")는 「개인정보 보호법」 및 관련 법령에서 정한 바를 준수하여 이용자의 개인정보를 처리합니다. 본 처리방침은 다음과 같은 내용을 담고 있습니다.

---

## 제1조 (처리 목적)

회사는 다음 목적을 위하여 개인정보를 처리합니다.

| 목적 | 처리 내용 |
|---|---|
| 회원관리 | 가입 의사 확인, 본인 식별, 부정 이용 방지 |
| 서비스 제공 | 식단 기록 저장·동기화, 목표 추천, 알림 발송, 광고 노출, 인앱 결제 |
| 고객 응대 | 문의 처리, 공지·약관 변경 안내 |
| 통계·개선 | 서비스 이용 분석, 오류 진단, 기능 개선 |
| 법령 의무 이행 | 전자상거래법·세법 등 관련 법령 준수 |

## 제2조 (수집 항목)

### 회원가입·로그인 시
- 필수: 이메일 주소, 비밀번호(암호화 저장) 또는 Apple ID / Google 계정 식별자

### 서비스 이용 시
- 식사 기록: 음식명, 영양 정보, 식사 시각, 식사 슬롯
- 신체 정보: 키, 몸무게, 성별, 출생연도, 활동량(선택), 목표(선택)
- AI 입력 데이터: 사용자가 업로드한 음식 사진, 입력한 자연어 설명
- 알림 설정: 알림 받을 시간

### 자동 수집
- 디바이스 정보: OS·앱 버전, 기기 식별자(IDFA·광고 식별자)
- 푸시 알림 토큰 (알림 활성화 시)
- 접속 로그: IP, 접속 시각, 오류 로그

### 결제 시
- 구독 식별자, 결제 상태 (실제 카드 정보는 Apple/Google이 처리하며 회사는 보유하지 않음)

## 제3조 (보유 기간 및 파기)

| 항목 | 보유 기간 |
|---|---|
| 회원정보 | 회원 탈퇴 시까지 (탈퇴 즉시 파기) |
| 식사 기록·신체 정보·AI 입력 | 회원 탈퇴 시까지 |
| 음식 사진 | 회원이 해당 음식 삭제 시 즉시 파기 / 회원 탈퇴 시 일괄 파기 |
| 결제·환불 기록 | 5년 (전자상거래법) |
| 접속 로그 | 3개월 (통신비밀보호법) |

회원 탈퇴 시 위 보유 기간이 명시된 정보를 제외한 모든 개인정보는 지체 없이 파기됩니다.

## 제4조 (제3자 제공)

회사는 이용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 따라 요구되는 경우 또는 본 처리방침에 명시된 위탁 처리는 예외로 합니다.

## 제5조 (처리 위탁)

회사는 다음과 같이 개인정보 처리 업무를 외부 위탁하고 있습니다.

| 수탁자 | 위탁 업무 | 위탁 정보 | 국외 이전 |
|---|---|---|---|
| Supabase Inc. (미국) | 데이터베이스·인증·파일 저장 | 회원·식사·사진 등 전반 | 미국 |
| Cloudflare, Inc. (미국) | 웹 호스팅·서버리스 처리 | 접속 로그, 요청·응답 데이터 | 미국 |
| Google LLC (미국) | AI 음식 분석(Gemini API), 광고(AdMob) | AI 분석용 사진·텍스트, 광고 식별자 | 미국 |
| Apple Inc. (미국) | 인앱결제, 푸시 알림(APNs), Sign in with Apple | 결제·구독 정보, 푸시 토큰, Apple ID | 미국 |
| 식품의약품안전처 | 식품영양성분 API 조회 | 음식명(개인 식별 불가) | 국내 |

위탁업체는 수탁받은 정보를 다른 목적으로 활용할 수 없으며, 위탁 종료 또는 회원 탈퇴 시 해당 정보를 파기하도록 계약상 의무화되어 있습니다.

## 제6조 (AI 처리에 관한 특별 고지)

1. 사용자가 AI 음식 추가 기능을 사용할 경우, 입력한 **사진 또는 자연어 텍스트가 Google LLC의 Gemini API로 전송**됩니다.
2. Google은 해당 데이터를 모델 학습 목적으로 사용하지 않으며(Google 정책), 처리 후 일정 기간 내 파기합니다.
3. 회사가 음식 사진을 자체 저장하는 경우(Supabase Storage), 200×200 픽셀 썸네일로 압축되어 본인 계정 폴더에만 저장되며, 다른 사용자에게 공개되지 않습니다.
4. AI 분석을 원하지 않는 사용자는 직접 입력(수동) 기능만 사용해도 모든 핵심 기능을 이용할 수 있습니다.

## 제7조 (광고 식별자·맞춤형 광고)

1. 무료 사용자에게는 Google AdMob을 통한 광고가 노출됩니다.
2. 광고는 iOS의 App Tracking Transparency(ATT) 정책에 따라 사용자 동의를 받은 경우에 한해 맞춤형 광고로 제공되며, 동의하지 않는 경우 일반 광고가 노출됩니다.
3. 광고 식별자(IDFA, AAID)는 광고 ID 외 다른 개인정보와 결합되지 않습니다.
4. 유료 구독자에게는 광고가 노출되지 않습니다.

## 제8조 (정보주체의 권리)

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

1. **열람 요구**: 본인 정보 확인
2. **정정·삭제 요구**: 잘못된 정보 수정, 불필요한 정보 삭제
3. **처리 정지 요구**: 처리 중단 요청
4. **동의 철회**: 동의 기반 처리에 대한 철회
5. **회원 탈퇴**: 앱 내 설정 → 계정 → 회원 탈퇴 또는 mkjjo.mini@gmail.com 요청

권리 행사는 앱 내 기능 또는 운영 이메일로 요청할 수 있으며, 회사는 지체 없이 조치합니다.

## 제9조 (안전성 확보 조치)

회사는 개인정보의 안전한 처리를 위해 다음 조치를 시행합니다.

1. **암호화**: 비밀번호 해시 저장(bcrypt 등), 통신 구간 TLS 적용
2. **접근 통제**: 관리자 계정 이중 인증, 권한 분리
3. **데이터베이스 RLS**: Supabase Row-Level Security로 본인 데이터만 접근 가능
4. **저장 분리**: 음식 사진은 사용자별 폴더로 격리(타인 조회 불가)
5. **로그 모니터링**: 비정상 접근·오류 감지

## 제10조 (만 14세 미만 아동)

본 서비스는 만 14세 미만의 회원가입을 허용하지 않습니다. 회사가 만 14세 미만 가입을 인지한 경우 즉시 계정을 삭제하고 관련 정보를 파기합니다.
